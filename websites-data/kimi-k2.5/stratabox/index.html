Platform

Built around composable blocks.

Editors compose pages from typed blocks. Developers consume the same blocks through a typed API. The platform handles versioning, scheduling, localization, previews, and asset delivery.

▣

Composable schema

Define content types and blocks with a visual schema editor or by committing a schema.tb file. Migrations are diffed, reviewed, and rolled back per environment.

  • Typed references & embeds
  • Per-field localization
  • Backward-compatible deprecations
⟳

Real-time collaboration

Multi-cursor editing on every block. Suggestions, threads, and assignment live alongside the content. Conflict-free at the field level.

  • Per-block presence
  • Inline review & approval
  • Slack, Linear, Jira mirrors
⚡

Edge content API

Read your content from 280 edge POPs with stale-while-revalidate. GraphQL, REST, and a typed JS/TS client are all generated from the same schema.

  • Per-environment tokens
  • Preview & production fork
  • Stable webhooks & replay
