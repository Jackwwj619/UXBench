Getting started with Tessera

Install Tessera, open a database, and run your first analytical query against a Parquet file in under five minutes.

1. Install

Tessera ships as a single static binary. Pick the build for your platform:

# macOS (Apple Silicon or Intel)
curl -L https://tessera.example/install.sh | sh

# Linux (x86_64)
curl -LO https://tessera.example/dl/tessera-linux-x86_64.tar.gz
tar -xzf tessera-linux-x86_64.tar.gz && sudo mv tessera /usr/local/bin/

# Verify
tessera --version

2. Connect

Open an in-memory or file-backed database in your language of choice. The example below uses Python, but the same API exists for Node, Go, and Rust.

import tessera

# In-memory database — discarded when the process exits
db = tessera.connect(":memory:")

# File-backed — persists between runs
db = tessera.connect("analytics.tsr")

3. Your first query

Tessera reads Parquet, CSV, and Arrow files directly — no import step required.

SELECT region, SUM(amount_cents) / 100.0 AS revenue
FROM read_parquet('orders/*.parquet')
WHERE created_at >= '2026-01-01'
GROUP BY region
ORDER BY revenue DESC;
Tip: Tessera uses SIMD-accelerated vector kernels — for aggregations across millions of rows you should see sub-millisecond response times on a modern laptop.
