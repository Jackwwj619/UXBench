Error codes

All WeaveAPI errors are returned as a structured object. Use code for programmatic handling and message for display.

CodeHTTPMessageHow to handle

expired_card402The card has expiredPrompt user to update the card
incorrect_cvc402CVC check failedRe-ask for the CVC
processing_error502Issuer was unreachableSafe to retry with idempotency key
fraud_blocked402Blocked by our risk systemDo not retry; escalate via dashboard
three_d_secure_required4023DS authentication requiredRedirect to three_d_secure.url
currency_not_supported400Currency not enabled on accountEnable currency in dashboard
amount_too_small400Below minimum charge amountIncrease amount (min $0.50 USD)
amount_too_large400Above per-transaction maximumSplit the charge
