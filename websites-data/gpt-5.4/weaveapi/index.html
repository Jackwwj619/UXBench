WeaveAPI is a payments-as-an-API platform built for backend engineers who want to ship value capture without inheriting a banking compliance department.

Quickstart

The most basic flow: collect a payment method, create a charge, capture funds.

Authentication

WeaveAPI uses API keys. Test keys are prefixed sk_test_; live keys are sk_live_. Send your key in the Authorization header as a bearer token.

Idempotency

Every state-changing request accepts an Idempotency-Key header. Retry safely: a retry with the same key returns the original response, even if your client retried after a timeout.

Pagination

List endpoints use cursor-based pagination. has_more tells you when you've reached the end; next_cursor is the opaque token for the next page.
