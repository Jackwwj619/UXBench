Charges

Use the Charges API to capture value from a payment method. A charge is the most atomic state change in WeaveAPI: money moved from your customer to you.

The Charge object

AttributeTypeDescription
idstringUnique identifier, ch_…
objectstringAlways "charge"
amountintegerAmount in the smallest currency unit (cents for USD)
currencystringISO 4217 code, lowercase
customerstringCustomer ID, or null for guest charges
statusenumpending · succeeded · failed · refunded
capturedbooleanWhether funds have been captured. False after a successful authorize without capture.
refundedbooleanTrue if fully refunded
amount_refundedintegerSum of refunds in smallest currency unit
payment_methodstringPayment method ID, pm_…
descriptionstringFree-form description (≤500 chars)
metadataobjectUp to 50 user-supplied key-value pairs
statement_descriptorstringUp to 22 chars; shown on the buyer's statement
failure_codestringSet when status === "failed"
failure_messagestringHuman-readable failure reason
receipt_urlstringHosted receipt URL after successful capture
createdintegerUnix timestamp
livemodebooleanfalse when using test keys

Create a charge

POST /v1/charges

Parameters

amountinteger · requiredSmallest currency unit
currencystring · requiredusd · eur · gbp · jpy
payment_methodstring · requiredPayment method ID
customerstring · optionalAttach this charge to a customer
captureboolean · optionalIf false, only authorize
descriptionstring · optionalInternal description
metadataobject · optionalUp to 50 keys

Example

Returns


    


    

      
Retrieve a charge

      
GET /v1/charges/{id}

      
Returns the charge object for the given ID.

      

    


    

      
Capture a charge

      
POST /v1/charges/{id}/capture

      
Captures a previously authorized but uncaptured charge. Optionally specify an amount to capture less than the original authorization.

      

    


    

      
Refund a charge

      
POST /v1/charges/{id}/refund

      
Issue a full or partial refund. Refunds settle back to the original payment method within 5–10 business days.

      

    


    

      
List charges

      
GET /v1/charges

      
Optional filters: customer, status, created[gte], limit (1–100, default 25).
