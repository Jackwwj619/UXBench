Quickstart

Drop a .codekite.yml at the root of your repo and push.

A minimal config

version: 2.1
jobs:
  test:
    runs-on: linux/x86
    steps:
      - checkout
      - run: pnpm install --frozen-lockfile
      - run: pnpm test --shard $CK_SHARD/$CK_TOTAL_SHARDS
    parallel: 8

That's it. Push a commit — your first build runs in under a minute.

Parallel jobs

The parallel key splits a job across multiple runners. Use the $CK_SHARD and $CK_TOTAL_SHARDS variables in your test command to slice work between shards.
