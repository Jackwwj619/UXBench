Chain rule — when both functions move

Calculus · single variable · last reply 12:08 PT · Atlas-3 model
SA

I keep getting tangled up when I have to differentiate sin(x²). Why doesn't it just become cos(x²)? Walk me through it like I'm just learning the chain rule.

A

Great question — this is the most common chain-rule slip. The short answer: cos(x²) would be right if the inside were just x. But the inside isn't x; it's x², which is itself a function that changes when x moves.

The chain rule says: when one function is wrapped around another,

Chain rule · for d/dx of f(g(x))
ddx f(g(x)) = f'(g(x)) · g'(x)

So when you see sin(x²), label the parts:

  • Outer function: f(u) = sin(u)
  • Inner function: g(x) = x²

Differentiate each on its own:

  • f'(u) = cos(u)
  • g'(x) = 2x

Now glue them together, keeping the inner inside the outer's derivative:

ddx sin(x²) = cos(x²) · 2x = 2x cos(x²)

That extra 2x is the entire reason chain rule exists. It's the rate at which the inside is changing.

One-line rule of thumb: Derive the outside, leave the inside alone, then multiply by the inside's derivative.
SA

Okay, that landed. Can you show me the same idea on a harder one — something with three nested layers — and break it into actual steps I can follow?

A

Yes. Here's a three-layer example, with step-by-step mode on. We'll differentiate:

h(x) = ln(cos(x³))
  1. Step 1. Identify the layers from the outside in.
    • Outer (1): ln(•)
    • Middle (2): cos(•)
    • Inner (3): x³
  2. Step 2. Derive each layer in isolation.
    • d/du ln(u) = 1/u
    • d/dv cos(v) = −sin(v)
    • d/dx x³ = 3x²
  3. Step 3. Chain them, outer first.
    h'(x) = 1cos(x³) · (−sin(x³)) · 3x²
  4. Step 4. Simplify.
    h'(x) = −3x² tan(x³)

    Because sin/cos = tan, and a negative pulls out front. Clean!

Try this kind of unpacking on the practice problems in the right pane — start with #1.

Can you also write a tiny Python helper that prints the derivative for me using sympy, so I can sanity-check my work?

A

Sure. Here's a 12-line script. Save as derive.py; it takes an expression as a string and prints the simplified derivative.

python · derive.py 
from sympy import symbols, diff, simplify, sympify

def derive(expr_str: str, var: str = "x"):
    x = symbols(var)
    expr = sympify(expr_str)
    d = simplify(diff(expr, x))
    return d

if __name__ == "__main__":
    print(derive("sin(x**2)"))      # → 2*x*cos(x**2)
    print(derive("ln(cos(x**3))"))  # → -3*x**2*tan(x**3)
Output 2*x*cos(x**2) -3*x**2*tan(x**3)

That matches what we worked out by hand on both examples. Try plugging in tan(sqrt(x)) next — same recipe, three layers again.
