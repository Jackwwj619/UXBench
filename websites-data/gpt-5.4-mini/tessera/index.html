The embeddable SQL engine for fast local analytics.

Tessera runs in your process, reads Parquet and CSV directly, and ships SIMD-optimized vector kernels for sub-millisecond aggregation over millions of rows.

Get started → View reference
SELECT
SELECT region, SUM(amount_cents) AS revenue
FROM read_parquet('orders/*.parquet')
WHERE created_at >= '2026-01-01'
GROUP BY region
ORDER BY revenue DESC;

1 · Install

# macOS / Linux
curl -fsSL https://tessera.dev/install.sh | sh

Single-file binary, ~12 MB. No service to run.

2 · Connect

# Python
import tessera
db = tessera.connect("analytics.tdb")
db.sql("SELECT 1").fetchall()
