Reference · v3.4

API reference.

Every public symbol in runeforge and @runeforge/react. Re-export-only modules (runeforge/devtools, runeforge/utils) are linked at the bottom.

function

forge(definition, options?)

Available since v1.0 · Updated in v3.0 (action signature)

Creates a store from a definition object. The shape of definition.state and definition.actions is inferred — TypeScript users get full autocomplete and type-checking with no extra annotations.

Signature

function forge<S, A>(
  definition: { state: S; actions: A },
  options?: { name?: string; persist?: boolean | PersistConfig }
): Store<S, A>;

Parameters

NameTypeDescription
definition.stateObjectInitial state. Must be a plain object (or a value compatible with structuredClone).
definition.actionsMap<string, fn>Map of action functions. Each receives state as its first argument and may take any number of additional arguments.
options.namestringOverride the auto-derived debug name. Visible in devtools and persisted storage keys.
options.persistboolean | PersistConfigPersist this store to localStorage (or a custom adapter). See Persistence.

Returns

A Store<S, A> object with get(), set(), subscribe(), select(), reset(), toJSON(), fromJSON(), and all your action methods at the top level.

Example

const counter = forge({
  state: { count: 0, step: 1 },
  actions: {
    inc:     (s)              => ({ count: s.count + s.step }),
    setStep: (s, step: number) => ({ step }),
  },
}, { name: "counter", persist: true });
Version history
  • v3.4 (2026-04) — added options.persist.
  • v3.0 (2025-11) — actions now take state as first argument (previously this).
  • v2.2 (2025-04) — automatic debug name from call-site stack.
  • v1.0 (2024-08) — introduced.
function

derive(inputs, fn)

Available since v2.0

Creates a derived store from one or more input stores. fn runs only when at least one input has changed, and the result is shallow-compared before notifying subscribers — so identical outputs don't emit.

Signature

function derive<Inputs extends Store[], Out>(
  inputs: [...Inputs],
  fn: (...states: { [K in keyof Inputs]: StoreState<Inputs[K]> }) => Out
): DerivedStore<Out>;

Example

const visibleTodos = derive([todos, filter], (t, f) =>
  f.mode === "done" ? t.items.filter(x => x.done) : t.items
);
Don't subscribe inside fn. A derive function must be pure and synchronous. Side effects (logging, fetching, subscribing) belong in an effect.
function

use(middleware)

Available since v2.4

Installs an action-level middleware. Middleware wrap every committed action across every store. Use this for logging, devtools, persistence, time-travel.

function use(mw: (next: Dispatch) => Dispatch): () => void;
use((next) => (action, args) => {
  console.log("→", action.name, args);
  return next(action, args);
});

Calling use() returns a function that uninstalls the middleware. Middleware run in install order.

helper

asyncSlice<T>(options?)

Available since v3.0

Returns { status, data, error } with the right types for async state. Designed to be spread into state alongside your own fields.

const user = forge({
  state: { ...asyncSlice<User>(), lastFetch: 0 },
  actions: { /* … */ },
});
helper

listSlice<T>()

Available since v3.1

Returns a state + actions pair for a keyed collection. The action set covers the common CRUD operations.

{ state: { items: T[] }, actions: (key: keyof T) => ListActions<T> }

Generated actions: add, remove, replace, update, clear, byId, has, count.

helper

formSlice<T>()

Available since v3.2

Adds values, errors, touched, submitting, and matching actions. Pair with a validation function for typed form state.

middleware

devtools(options?)

Available since v1.0

Installs the Runeforge browser-devtools middleware. Renders an action log with diffs, supports "jump to" time-travel, and exposes per-store snapshots.

devtools({ name: "My App", maxHistory: 200 });

React adapter (@runeforge/react)

hook

useStore(store, selector?, equality?)

Subscribes a component to a store. Returns the selected value. Triggers a re-render only when the selected value changes by the chosen equality function.

function useStore<S, T = S>(
  store: Store<S, any>,
  selector?: (s: S) => T,
  equality?: (a: T, b: T) => boolean
): T;
hook

useSnapshot(store)

Reads the current state once (no subscription). Useful for one-off reads outside the render cycle.

component

<Provider stores={[…]} /> (optional)

Only needed if you want SSR-safe per-request isolation. Most apps don't need this.

Error codes

CodeMeaningHow to fix
RF001Action returned non-object.Return a partial state object. To return identity, return s.
RF002Mutation detected in action.Use spread / map / filter. Don't assign to existing state.
RF005derive() loop detected.A derived store depends on itself transitively. Break the cycle.
RF009Persist adapter rejected payload.Check it's serializable; use options.persist.serializer for custom types.
RF014useStore called outside React tree.Use store.get() instead.
RF019SSR hydration mismatch.Pass server state into store.fromJSON() before render.
