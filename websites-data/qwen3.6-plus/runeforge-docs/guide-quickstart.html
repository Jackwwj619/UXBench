Quickstart · 5 minutes

From zero to a working app.

In the next five minutes you'll install Runeforge, build a counter, build a todo list, and wire up an async fetcher. By the end you'll have used 90% of the API.

Prerequisites: Node 20+ (or Bun). The examples use React but everything maps 1:1 to Solid, Svelte, Vue, and vanilla JS.

Step 1 · Install

Create a fresh app with whatever template you like. Then install Runeforge and the React adapter.

# inside your app directory
npm install runeforge @runeforge/react

Step 2 · A counter store

The smallest useful store has one piece of state and one action. Both are inferred from the object you pass to forge().

// stores/counter.ts
import { forge } from "runeforge";

export const counter = forge({
  state: { count: 0 },
  actions: {
    increment: (s) => ({ count: s.count + 1 }),
    decrement: (s) => ({ count: s.count - 1 }),
    reset:     ()  => ({ count: 0 }),
  },
});

Use it in a component with useStore:

// Counter.tsx
import { useStore } from "@runeforge/react";
import { counter } from "./stores/counter";

export function Counter() {
  const count = useStore(counter, (s) => s.count);
  return (
    <div>
      <h2>{count}</h2>
      <button onClick={counter.decrement}>-</button>
      <button onClick={counter.increment}>+</button>
      <button onClick={counter.reset}>reset</button>
    </div>
  );
}

Notice three things:

  • No provider. The store is just an import — it's already global.
  • The component subscribes to a selector (s.count), not the whole store. If another part of state changed, this component would not re-render.
  • Actions are called like ordinary methods. There's no dispatch().

Step 3 · A todo list (and a derived store)

For richer state, use a slice for todos and another for the filter. Then derive a third store that combines them.

// stores/todos.ts
import { forge, derive } from "runeforge";

export const todos = forge({
  state: { items: [] as { id: number; text: string; done: boolean }[] },
  actions: {
    add:    (s, text: string)         => ({ items: [...s.items, { id: Date.now(), text, done: false }] }),
    toggle: (s, id: number)           => ({ items: s.items.map(t => t.id === id ? { ...t, done: !t.done } : t) }),
    remove: (s, id: number)           => ({ items: s.items.filter(t => t.id !== id) }),
    clear:  (s)                        => ({ items: s.items.filter(t => !t.done) }),
  },
});

export const filter = forge({
  state: { mode: "all" as "all" | "active" | "done" },
  actions: {
    setMode: (s, mode) => ({ mode }),
  },
});

// derive() runs only when its inputs change.
export const visibleTodos = derive([todos, filter], (t, f) => {
  if (f.mode === "all")    return t.items;
  if (f.mode === "active") return t.items.filter(x => !x.done);
  return t.items.filter(x => x.done);
});

In the component, you subscribe to the derived store the same way you subscribe to a regular one:

const visible = useStore(visibleTodos);
return visible.map(t => <Todo key={t.id} todo={t} />);

Step 4 · Async (the easy way)

Async work belongs in effects. Effects can read and write any store, await whatever they want, and report status into a status field. Runeforge ships an asyncSlice() helper that gives you a typed status object for free.

import { forge, asyncSlice } from "runeforge";

export const users = forge({
  state: { ...asyncSlice<User[]>() },
  actions: {
    async load(s) {
      if (s.status === "loading") return s;
      try {
        const r = await fetch("/api/users");
        const data = await r.json();
        return { status: "ready", data, error: null };
      } catch (e) {
        return { status: "error", data: null, error: e.message };
      }
    },
  },
});

Inside the component:

const { status, data, error } = useStore(users);
useEffect(() => { users.load(); }, []);

if (status === "loading") return <Spinner />;
if (status === "error")   return <Error msg={error} />;
return <UserList users={data} />;

Step 5 · Devtools (optional, but you want this)

Add the devtools middleware once. From then on, every action shows up in the Runeforge browser extension with a diff, a stack trace, and a "go back to here" button.

import { devtools } from "runeforge/devtools";
devtools({ name: "My App" });

You're done.

That's the whole library. Most apps never reach for the advanced features (atoms, snapshots, time-travel, persistence). When you need them, the patterns work the same way — they're built on the same three concepts.

What now? Browse the API reference for exact signatures, or open Examples for full apps you can fork.
