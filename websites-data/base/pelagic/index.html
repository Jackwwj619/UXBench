Changelog

v0.42.1

HNSW build is 2.3× faster on AVX-512. New --ef-build-auto heuristic. Fixes a rare segfault on filtered queries with empty bitmaps.

v0.42.0

Hybrid retrieval GA. Sparse vectors first-class. retrieve() now accepts mixed dense/sparse with weights.

v0.41.3

Filter pushdown for boolean and range predicates. ~38% latency reduction on large filtered sets.

v0.41.0

Coordinator HA — leader election via Raft. Rolling upgrade path documented.

v0.40.0

Multi-tenancy: namespaces with per-namespace quotas, IAM scopes, and per-tenant snapshots.
